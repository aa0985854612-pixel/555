肉豬紀錄管理 App — Windows／手機版 v1.2.1

【下載與啟動】
1. 下載 pigledger-windows-1.2.1.zip，右鍵 → 全部解壓縮。
2. 筆電本機：雙擊 START_WINDOWS.bat。
   手機外出／行動網路：雙擊 START_PHONE.bat。
3. 第一次在黑色視窗設定帳號（預設名稱 farmadmin）與至少12字元密碼。
   密碼輸入不顯示字元是正常的，再輸入一次確認。
4. 瀏覽器開啟後用剛才設定的帳號密碼登入。
   已有筆電帳號時不重設、不重建。

【手機】
START_PHONE.bat 約需數十秒建立並檢查連線。
黑色視窗顯示「手機網址（已檢查連線）」後，把網址傳給自己的手機。
Safari／Chrome開啟並登入；手機不必和筆電連同一Wi-Fi。
網址也放在 %LOCALAPPDATA%\PigLedger\PHONE_URL.txt，停止時移除。
手機與本機啟動器使用同一份筆電資料及帳號。
使用時保留黑色視窗，筆電保持開機、連網、接上電源，不要睡眠。
Windows設定 → 系統 → 電源與電池／電源與睡眠，將接電源時睡眠設為永不。
不要合上螢幕蓋後讓筆電睡眠；結束時在黑色視窗按 Ctrl+C，再關視窗。
重新啟動可能換網址，舊捷徑需改新網址，資料仍在同一筆電。
這是 Cloudflare Quick Tunnel 臨時連線，沒有全天候服務保證。
固定正式網址請使用 docs/DEPLOY.md 的雲端部署方式。

【加入主畫面】
iPhone／iPad：Safari開HTTPS網址 → 分享 → 加入主畫面。
Android：Chrome → 選單 → 安裝／加入主畫面。
網址變更需重新加入及登入。不要透過檔案預覽開HTML。

【匯入原資料】
首次使用筆電，程式包不會帶入ChatGPT開發環境的資料或密碼。
設定 → Excel資料移入與核對，選你手上的原始 XLSX。
填各棟頭數的實際盤點日期；每行填 棟號/頭數，例如 1/100、2/200。
已出完棟號另填，逗號分隔。先預覽，再匯入。
相同檔案重送不重複，也不覆蓋管理員更正。
原檔、舊表、公式及備註保留；來源紀錄唯讀、分棟數標示暫定。
缺日期、樣本頭數或各棟分母的計算顯示未知。
來源基準已包含原表截至日異動，新日常登記從次日開始。
基準日存量需更正可由管理員登記「盤點調整」，原始檔不被改寫。
詳見 docs/EXCEL_IMPORT.md。

【每天使用】
每日登記填實際出豬、淘汰、死亡；同一頭只能扣其中一種。
飼料紀錄填到料與實耗，秤重紀錄填實測重量。
週期統計看結果，歷史紀錄查詢及CSV匯出。資料不足顯示 —。

【斷線】
連線沒成功時不會顯示已取得可用手機網址。
App顯示尚未確認儲存時，保留原筆重試，不要重填。
停止／更換網址前先確認沒有未確認的紀錄；換網址後先查歷史避免人工重填。
網路阻擋Cloudflare時先用 START_WINDOWS.bat 在筆電登記。
公司網路可能需允許 Cloudflare Tunnel 對外 TCP7844。

【資料、更新與帳號】
資料在 %LOCALAPPDATA%\PigLedger\data\pigledger.sqlite3。
更新前在設定下載完整備份JSON，關掉舊視窗，再解壓啟動新版。
不要刪除上述使用者資料夾。schema2→3 自動先備份、保留帳號及紀錄。
備份含原始Excel與帳號密碼雜湊，請私密保存。
公開手機服務使用HTTPS Secure cookie及伺服器權限驗證，未登入不能讀紀錄。

【驗收】
內附官方Python3.14.8及cloudflared2026.10.0，适用Windows10/11 x64（Intel/AMD）。
已核對官方來源、checksum、ZIP與Linux共用程式／瀏覽器測試。
本雲端是Linux，尚未在真實Windows雙擊驗收。
雲端網路阻擋Cloudflare API，真正手機外出網址需在你的筆電首次啟動驗證。
錯誤時保留黑色視窗並提供錯誤文字；不要貼密碼。

最後使用檔案：筆電本機 START_WINDOWS.bat；手機外出 START_PHONE.bat。
