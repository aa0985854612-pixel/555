2026-11-05。原設定清單依資料建立順序顯示，且隱藏棟舍刪除按鈕；共用紀錄作廢流程也不支援棟舍。這次直接修正原設定與既有棟舍CRUD路徑，不另外建立管理頁或資料來源。

- `app/static/compact.js`：獨立棟舍清單共用 `orderedBarns()` 數字排序；批號分組及其日期順序保持。管理員每筆有更正／刪除入口，專用確認視窗顯示原棟名與關聯，不會把未儲存改名當成刪除目標。取消保留草稿，刪除其他棟舍不清空正在編輯的資料。

已有批次（含已結束）、料桶（含停用）或快捷來源關聯的棟舍不能直接刪除，視窗列明原因；後端再次驗證，無法繞過。沒有級聯刪除、批次搬移或正式農場資料清理。刪除僅將原ID保留為軟刪除紀錄，操作歷程保留原值。
