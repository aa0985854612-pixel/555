# 2.0.66 — 飼料數量增減不再從0.000001開始

使用者截圖顯示數量欄位按增減後出現0.000001。前版只移除小數尾零，沒有改掉HTML數量下限；瀏覽器把原本`min="0.000001"`當作空白增減的起點。

`app/static/feed.js`將主要飼料登記數量欄的原生增減基準改為`min="0"`，保留`step="any"`以免阻擋原有1.5噸等真實小數量。實際Chromium驗證空白按↑變1，再按為2、3，按↓回2。欄位不會因這次修正自動填0或更改既有輸入；零與負數仍由原伺服器正數驗證拒絕正式寫入。原料別記憶、公斤／噸換算及儲存流程保留。

驗證：

- `tests/feed_memory_browser.py`：8個情境通過；加入空白原生數量欄↑／↓回歸檢查，並保留2.000→2、1.50→1.5、正式儲存2000公斤、料別記憶、雙裝置及A4最新料別驗證。
- `tests/feed_bulk_browser.py`：7個情境通過，既有清單、編輯、單位數量與重試維持正確。
- JavaScript語法及`git diff --check`通過。合計15個瀏覽器情境，以隔離合成資料執行；沒有寫入正式農場或送通知。

後端邏輯與資料庫結構未修改，沒有為這次欄位屬性修正重跑前版800個單元／整合測試。沒有資料遷移。版本與快取標記更新為2.0.66，發布沿用原生Git部署，檢查READY、SHA、正式網域、既有飼料政策與台灣10點提醒。
