# PigLedger 1.8.5：不同進場日期的同批歸組

批次增加可選same_batch_as參照，與實際entry_date、進場頭數及轉棟cohort_id分開。管理員可將不同棟舍、不同日期的進場批次明確歸為同一組，原ID、紀錄與存欄不合併／重算。原來未指定歸組的同名不同日期仍分開；原Excel歷史批次禁止改來源歸屬。

整批查詢使用解析後的相同cohort key，並保留各棟實際日期。最早進場筆為基準，防止自指、循環與刪除仍被引用的基準。舊前端省略新欄位更正時，伺服器保留既有歸組，避免背景操作意外解除。直接API也要求管理員及正確revision。

不同週齡顯示依棟舍，而不是標示假的共同週齡或缺資料。批次總覽、共用歷史篩選、死亡統計與週表採相同歸組；新同批內部轉棟不重複增加整批分母。保留schema4及原資料庫。

## 正式保留與驗收

原15棟與21棟新一批使用不同批號符號、進場日而分開；處理時先備份，再對21棟新一批新增歸組參照並統一顯示批號。原15棟、已結束21棟、各棟數量、日期、均重、日齡、秤重、來源Excel及帳號保留；沒有把已結束21棟的歷史算入目前新批。

正式驗收核對所有非目標紀錄逐筆不變、單棟／全場頭數與進場分母不變、15／21新批共組、舊21批次仍獨立，以及統計／週表使用同一範圍。數量依現存人工紀錄保留，不假設本次歸組代表重新確認進場數量。

尚未完成實體手機／Safari／印表機及使用真實密碼的互動登入驗收；本地瀏覽器與雲端程式讀回不代表這些測試已完成。
