# PigLedger 2.0.8：肉豬紀錄表精簡

依紙本參考整理重要欄位：批次／棟舍、進場總數、廠商／料別、出豬地點，另列各棟的實際進場日期、頭數、日齡及均重。每7天一欄，淘汰、死亡、叫料與正常出豬分開；期間合計與截至日期累計存欄／育成率分開。重複的異動摘要不再塞入週表，完整異動、來源及說明可展開，CSV保留完整資料。A4印表標籤精簡但不改數字或單位。

連結同批的不同進場日期與均重分開顯示；舊Excel只有整批進場數時，單棟不得編造。新增的是唯讀報表回應欄位，沒有資料表遷移、歷史回填或帳號更動。參考照片未作資料匯入。FCR公式與使用實際耗料的限制沿用原規則。
