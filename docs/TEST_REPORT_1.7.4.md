# PigLedger 1.7.4：隱藏零死亡項目

週期死亡清單只顯示查詢期間有死亡的批次；單棟明細也隱藏0隻。同批棟舍名稱仍保留，讓批次關係清楚。死亡數未知的批次／單棟仍顯示—與資料不足，不把未知當成0。可靠死亡合計為0且沒有待補列時，顯示「查詢期間沒有死亡紀錄」，並提供越南語文字。

只改清單呈現，原查詢、排序、期間死亡總數、來源資料、育成率、歷史及CSV保持。零死亡資料仍在API、原資料庫及其他完整統計中，沒有刪除或作廢紀錄。

## 本次實際驗證

- `tests/period_deaths_browser.py`：8組真實Chromium／隔離SQLite／HTTP情境通過。11批24棟合成資料，主清單由11列縮成5列，死亡合計仍8。各棟0隻不列出，批次名稱仍含所有相關棟舍。
- 保留歷史及CSV同條件合計；涵蓋跨日、已出清棟舍、分組限制、唯讀查詢。整段無死亡時顯示明確提示，繁中／越南語皆確認；缺資料用明確標示的API模擬，仍保留未知列。
- 6種寬度×2種語言×3種字級，共36種版面無整頁水平溢出；清單點擊入口仍至少44px。相同390px／中字合成資料，清單高度由1.7.3的1378px降為626px。
- `python3 -m unittest discover -s tests -p test_period_deaths.py -v`：10項相關統計／來源／日期／篩選測試通過。
- `tests/pwa_test.py`：5項版本快取、未儲存內容保護及API不快取檢查通過。`node --check app/static/redesign.js`通過。
