# PigLedger 2.0.14：死亡備註依棟舍分欄

死亡備註改成每棟一欄，標題為第5棟、第6棟等，日期明細由上而下排列，例如9/15 死亡1隻。同批各棟依數字排序，沒有死亡紀錄的棟舍只保留標題、明細留白，不寫0。上方每週合計及右側出豬備註維持。

預覽依同一份唯讀報表列完整分組；CSV仍保留全部逐週及逐筆棟舍來源明細。A4摘要每棟先列最多6筆，更多筆數在所屬棟舍下方提示詳CSV。單頁最多呈現3棟備註欄，額外棟數也明示詳CSV；預覽不省略。沒有修改任何事件、頭數、批次ID或資料庫結構。
