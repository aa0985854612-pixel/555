# PigLedger 2.0.5：已略過核對視為完成

管理員確認略過舊批次後，將當下的指定缺項保存為 `completed_skipped`，伺服器不再將它們列入待補清單或待補數字。原始資料、未知數值、存欄、育成率、歷史明細與巡場確認皆不因略過而變動。

完成狀態綁定固定批次 ID、來源項目 ID 與當時的缺項欄位。其他批次、新批次及新增缺項繼續正常提示。一般批次編輯、舊客戶端省略欄位、相同 Excel 再匯入與備份還原會保留狀態。管理員可透過批次 API 設 `quality_review: null` 撤銷完成狀態；唯讀與編輯角色不能修改。

本版不新增資料表、不更換資料庫，也不將任何批次標為出完。資料補正時建立完整雲端備份並保留操作者、時間、原因與更正前後值。
