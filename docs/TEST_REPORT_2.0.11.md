# PigLedger 2.0.11：週表平均分排、完整叫料單行、獨立出豬備註

依使用者PDF照片修正：預排至32週，後面只有兩個空白預留欄，按欄數平均分成上下兩排。11週起的範例為上排11～22週、下排23～32週＋兩空欄，兩排各12欄。週齡未知不推測，32週後已有資料不刪除。

出豬備註移到下方獨立大欄，按日期排序，保留地點、頭數、棟舍及一般備註；上方改顯示週期範圍，各週的出豬及淘汰數保留。預覽及CSV完整列資料；單頁摘要先列12筆，其餘明確標示筆數及CSV入口，不靜默遺失。

叫料每筆一行，完整保留日期＋噸數＋料桶／棟號。Canvas PDF將每筆以一個有最大寬度的文字呼叫繪出，多筆依換行符號分行；不再按字元將日期或棟號拆行。預覽與原瀏覽器列印則以量測後的字級適配欄寬，保持nowrap。長表頭使用清楚的短標籤，避免正常出豬被截成省略標記。
