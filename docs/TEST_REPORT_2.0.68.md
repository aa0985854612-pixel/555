# 2.0.68 — 一頁A4、各棟死亡備註並排、紙本不列淘汰

使用者說明死亡備註的大框應讓8棟、14棟各自在旁邊接寫，且整份只要一頁。前版將各棟接成單一清單並產生續頁，不符合此要求。

`app/static/weekly-pdf.js`改為單一A4規劃及繪製：

- 每棟死亡備註保留獨立區塊，各棟標題並排對齊。紀錄較多時，在該棟自己的區域右側接寫，不將下一棟排在上一棟下面；多棟時按獨立區塊分列。
- 先量完整死亡與出豬備註所需空間，再量上方進場與週表明細。內容過多時壓縮上方行高、留白與字級，固定一頁；上方已讓出空間後，極大量備註才一併調整字級。所有數字均實際繪出，不裁切、不以省略符或第二頁代替。
- 飼料明細、進場前叫料、多期週欄及逐次售出數仍完整保留。列印預覽與下載PDF使用完全相同的單張影像。

`app/static/weekly-report.js`移除報表的淘汰週欄與淘汰合計；紙本出豬備註只列正常出豬。原資料庫中的淘汰紀錄、頭數扣除、總覽、週期統計與歷史查詢未刪除或改寫。`feed-receipts.js`同步更新單頁說明，另更新2.0.68版本／快取標記及文件。

- `tests/weekly_full_feed_browser.py`：5個情境通過，190筆飼料、70筆進場前叫料、同日日期一次及多期週欄皆固定一頁，原始數量完整，合計不重複。
