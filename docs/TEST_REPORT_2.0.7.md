# PigLedger 2.0.7：出豬備註（地點）

每日登記的正常出豬與淘汰增加選填地點：新北、南投、嘉義。以獨立欄位 `outgoing_destination` 保存，原一般備註保留。歷史紀錄、當日核對、一般CSV與每週肉豬紀錄表顯示原紀錄的地點。

肉豬紀錄表上方彙整選定範圍的地點，各週另列日期、地點、棟舍與頭數。預覽與CSV保留全部明細；A4直式摘要每週先列首筆，其餘以「+筆數」與明確說明提示，完整內容在CSV。39週81筆地點明細的合成測試仍為一張直式A4，並未縮放整頁。

舊資料不推測或自動補地點。舊客戶端更正出豬時省略新欄位會保留原地點；明確留空可清除。改成死亡等非出豬類型時不能帶入地點。原權限、版本衝突、同鍵重試與審核歷程沿用。欄位不參與頭數、育成率、ADG或FCR計算。
