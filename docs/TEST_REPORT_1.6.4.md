# PigLedger 1.6.4 數字密碼測試報告

新設、更改、首次設定及管理員重設密碼統一使用4～8位ASCII數字0～9，保留開頭的0；拒絕英文字、全形／其他Unicode數字、空白、符號、非字串及長度不符。伺服器共用一套驗證，網頁新密碼欄位設minlength／maxlength／pattern及numeric鍵盤，不能只繞過畫面就存不符密碼。登入及目前密碼欄保留既有密碼相容性，不套新形狀限制。

沿用scrypt安全雜湊、既有登入限流、CSRF、角色及修訂衝突。所有角色改自己密碼須驗證目前密碼；管理員重設別人密碼後要求首次更換。舊登入與一次性連結失效規則保留，操作紀錄不含密碼。管理員儲存帳號期間停用該列控制項，成功後讀取新revision，保留其他正在編輯列的焦點保護。

## 正式雲端與資料保留

改動前已核對當時正式資料、帳號及結構，並在原Turso建立持久備份。schema仍為4，不遷移或重新建立資料庫，不重設正式管理員或其他帳號；本版只改未來密碼寫入規則，既有雜湊不修改。

沿用原GitHub main、Vercel專案及HTTPS網址。部署後核對正式首頁、health、新密碼表單資產與SW版本；在真實Turso執行數字密碼雜湊／首次更換的暫時帳號交易後ROLLBACK，核對整份records、users、requests、audit與account_security不變。詳細HTTP及資料指紋結果保存在私密維護紀錄，測試帳號不會留在正式庫。

尚未驗收：使用者目前密碼的正式HTTPS互動登入、實體Android／iPhone鍵盤與密碼更改。沒有為測試要求、公開或重設使用者現有密碼。原Q版安裝圖示繼續沿用1.6.3的資產檔名；程式與manifest／SW更新至1.6.4。
