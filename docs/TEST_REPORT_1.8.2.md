# PigLedger 1.8.2：肉豬每週紀錄表

依使用者選擇，週期從進場日起每7天一欄，不採星期一的日曆週。整合在每日登記與週期統計，仍是原六頁；選一個批次及整批／單棟，產生紙本式死亡、正常出豬、淘汰、叫料週表。只讀取已保存資料，不寫入報表用的重複異動。

提供A4橫向列印／透過瀏覽器另存PDF、UTF-8 CSV週表及分棟日期明細。長週期每13欄分區，不縮小整張App畫面。第幾週從進場當日的日齡計算，與已滿週齡區分；未知日齡使用第幾期。期間合計與累計育成率明確分開。

## 本地及模擬

- `sh scripts/check.sh`：244項單元／整合測試及8份JavaScript語法檢查通過。其中新增11項每週報表測試，原233項維持。
- 新測試涵蓋進場日起7天邊界、第幾週、正常出豬與淘汰／死亡分開、只扣死亡的育成率、單棟／整批叫料加總、全場未分配叫料不猜分配、部分週日期、未到日期不填0、作廢排除、無效範圍及最多三年限制。
- 合成Excel歷史與人工異動共用同一來源識別，週表不重複累加基準存欄；整批5隻出豬有3隻未分棟時，整批可呈現5，單棟保持待補及已知數。缺日期的來源只影響對應來源截止日前的週，不把後續新週永遠標成未知。報表運算不修改原資料。
- `tests/weekly_report_browser.py`：9組真實Chromium／隔離SQLite／HTTP情境，實際下載CSV與生成PDF。驗證週表與逐日單棟異動、期間合計一致；人工測試資料不含使用者Excel／照片。
- 短期測試表產生一頁A4橫向PDF，轉圖核對基本資料、各列及合計；長週期分13欄並保留未到日期空白，表格不溢出頁面。
- 4寬度×2語言×3字級，共24種預覽布局無整頁橫向溢出。手機表格可在預覽內左右查看。產生／關閉報表保留每日登記草稿與批次；改條件後舊匯出失效，需重新產生。
- 唯讀可查與匯出，未登入的報表API回401；帳號雜湊保留，沒有未捕捉JavaScript錯誤。沒有增加寫入端點或放寬角色權限。
- `tests/weighing_report_browser.py`：8組原秤重PDF／CSV回歸通過；`tests/pwa_test.py`：5項新版快取與草稿保護通過。API與報表內容不進離線資產快取。

## 正式資料與驗收限制

修改前已備份原Turso：70筆records、4個帳號、12筆秤重、110筆操作紀錄。schema4不變，不重新匯入Excel或重設管理員；沿用原GitHub main、Vercel專案、正式網址及資料庫。

正式驗收檢查HTTPS版本與資產內容，從原Turso重新讀取每批報表，核對死亡／出豬／淘汰與共用歷史篩選一致、累計育成率與既有統計相同，並比對資料及帳號指紋。詳細結果保存在私密維護驗收檔，不永久寫入測試資料。

Safari、實體iPhone／Android、系統分享、實體印表機及使用真實密碼的互動登入仍未驗收；不能以Chromium視窗及生成PDF宣稱實機通過。全場未歸屬叫料、缺日期及不可靠棟舍分配仍列待補，不捏造補齊。沒有新增自動叫料、配送或採食預測。
