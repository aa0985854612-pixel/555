# 2.0.46 批次與棟舍自助管理

管理員可從設定與總覽批次卡片，集中修改整批批號、棟名、入場頭數／日期／均重、狀態、基準日齡、分次進場及報表起始日。獨立盤點模式保存存欄差額，保留原始進場數。修改需先預覽各棟與整批前後變化，再確認儲存；不直接寫入任意JSON。

後端使用既有records、requests與audit，沒有資料表或資料格式遷移。全批成員／版本、管理員權限、欄位白名單、原因、原始Excel合計、來源完整度、日期和未來存欄均驗證。預覽綁定使用者、修改內容與現有版本；同時修改會拒絕舊預覽。所有更正同交易寫入，斷線使用原請求鍵重試；相同數字的另次盤點會新增獨立紀錄。回傳快照重新展開匯入來源，保存的records不含計算快取。

棟舍改名後，舊來源以原批次的barn_id維持關聯；後續Excel匯入優先沿用已知的原棟ID。原始Excel內容、來源事件ID及歷史異動不重寫。
