# 2.0.54 LINE群組照片先待確認

新增簽章驗證的LINE Webhook、管理員設定／狀態API、一次性10分鐘群組綁定、解除、OpenAI圖片辨識、最近收圖狀態及待確認清單直接連結。只有已綁定群組的圖片能進入辨識，群組文字／postback不能直接確認；正式入帳沿用2.0.53的登入、角色、修正預覽、勾選及原子交易。

原始照片只在辨識請求記憶體中處理；伺服器只保留文字轉錄、來源雜湊、去重收據、重試及綁定狀態。不將服務金鑰、原始groupId、LINE userId或replyToken寫入資料庫／一般前端snapshot。環境變數只回傳存在與否，設定仍需管理員session及CSRF。租約防止並行重送重複辨識；照片內容雜湊和固定冪等鍵避免重複草稿，處理儲存成功後失去回覆、LINE回覆失敗及多張照片分次重送。解除或停用管理員後，交易內guard防止進行中的辨識繼續建立草稿。

辨識採結構化輸出，再驗證數量／日期／料桶／料別與文字長度。不清楚的欄位可以留空待改，未補齊不能正式確認。藥名、kg／ppm及到料／卸料備註保留，既有原叫料與確認分攤保護不變。圖片類型、大小、每小時數量均有限制，公開URL的圖片不抓取，供應商請求固定目的地且不跟隨重導。

驗證：655項單元／整合測試與全部JavaScript語法檢查通過；其中49項新測試涵蓋本機SQLite、Hrana/Turso模擬、簽章先於解析、未綁定／其他群組／私訊忽略、一次性過期碼、角色／版本、停用及降權重新綁定、跨日期待確認、正式統計不變、群組確認不能入帳、網站確認保留原紀錄分攤、圖片重傳、並行租約、網路重試、回覆遺失、解除時交易guard、備份、額度限制、模型輸入驗證、結構化辨識參數及實際HTTP端點。最後針對SQL最近狀態／時段限制查詢調整，再執行這49項測試。

真實Chromium／HTTP的6項新流程檢查通過：缺設定提示與禁止綁定、管理員產碼及簽章群組綁定、320／390／768／1440寬度及中越語文、照片重送只產生一張可改草稿、清單直接連結及修改4→5噸後明確確認、解除與唯讀權限。目視檢查手機設定圖。另8項原每日飼料草稿瀏覽器檢查通過，涵蓋並行來源失效、修改、取消、斷線重試及帳號隔離。測試均使用隔離合成資料；LINE下載、辨識及回覆以測試替身執行，未發送真實群組訊息、照片或通知。

正式Vercel環境唯讀檢查三項必要變數名稱皆未設定，所以目前是可設定的串接程式，尚未啟用真實LINE群組。環境變數內容、OpenAI額度、實際圖片辨識品質、LINE webhook啟用／重送及群組權限需要設定後再做真實驗證。不能將模擬測試結果描述成已經成功連上群組。

發布沿用既有GitHub→Vercel原生整合，核對READY、Git提交及正式別名；不建立額外臨時驗證部署。沒有新增正式農場草稿、叫料或改動原始進場／存欄資料；既有台灣上午10點提醒排程與通知設定保留。
