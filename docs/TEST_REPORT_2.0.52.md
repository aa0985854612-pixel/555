# 2.0.52 總覽表頭簡化

全場總覽的三欄縮短為「死亡、出豬、淘汰」，越南文同步使用短詞。僅這三個表頭設定不換行，避免窄螢幕顯示成上下兩行。既有統計說明保留累計期間與正常出豬／淘汰的區別。數值、欄位順序、資料結構及通知排程不變。

驗證：沿用既有總覽Chromium／HTTP視覺檢查，涵蓋中／越文及320、390、768、1642寬度的大字模式，三個短標題皆完整單行，欄內數字不溢位。批次計算說明及管理入口可操作，未知值與0的呈現正常，農場records未改變，無JavaScript錯誤。已目視檢查390寬度畫面；compact.js語法與git diff --check通過。這是低影響標題與CSS變更，沒有新增測試套件或改變後端計算。
