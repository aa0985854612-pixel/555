# 2.0.62 — 肉豬紀錄表先選批號

肉豬紀錄表改為先選「批號」，再選該批「棟舍」。批號選單顯示「批號｜所屬棟舍」，移除進場日期；完整批次ID與原始日期仍留在資料及報表中。切換批號會重新提供該批棟舍，預設同批全部棟舍，也可再選單棟。批號不受先前棟舍限制，舊批次可直接切換。中越語說明及選項同步調整。

保留2.0.61的全部已登記資料、未來日期、原始飼料單一來源、PDF／列印／CSV及更正刪除同步，不恢復日期篩選。
