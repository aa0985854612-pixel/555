# 2.0.31 大字工作行事曆

A4改用實際文字高度安排七天的行高。每天重複的固定工作集中在頁首，日期表格保留每週固定與單日臨時工作，減少重複內容。預設工作字15.5pt，資料量增加時最低14pt；日期及欄名至少14pt。大量文字仍保留同週續頁，無內容截斷。

每日工作分組只採用全部七天皆有的相同固定工作，並保留重複工作出現次數；單日工作不分組。只調整PDF呈現，不更改原工作紀錄。

驗證：

- `sh scripts/check.sh`：556個單元／整合測試與17個JavaScript語法檢查。
- `python3 tests/work_calendar_browser.py`：14項通過。新增42項工作的一週仍為一張A4、字體至少14pt、七天共同工作分組、重複工作次數及不修改模型的測試。既有權限、斷線重試、手機、預覽與下載及密集文字續頁均通過。
- 實際本週34項固定與8項臨時工作，`pdfinfo`確認一張595.28 × 841.89pt直式A4；所有工作、日期、頭數及備註皆完整繪出，工作字體15.5pt，已檢視轉圖版面。
- 臨時工作另以受保護備份、單一交易、正常欄位驗證及冪等請求登記；在SQLite與模擬Turso驗證重試、下週不重複、原工作／帳號／畜牧紀錄保持不變。出豬工作只登記在行事曆，不產生存欄異動。
