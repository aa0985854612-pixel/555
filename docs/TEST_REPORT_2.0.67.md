# 2.0.67 — 完整紙本、共用桶平均分料及現況總覽

本版依使用者六項要求調整既有報表與首頁，保留原資料、資料庫、紀錄ID、修改歷程與一般歷史查詢。

1. 肉豬紀錄表移除CSV按鈕、產生程式及CSV導引文字，保留原A4 PDF、預覽和瀏覽器列印。其他管理頁的原匯出功能不受影響。
2. 出豬與死亡備註依日期先向下寫，使用剩餘整個寫字區；第一欄放滿才接右側第二欄。兩欄都滿時產生A4續頁，逐筆與長文字不省略。出豬備註採日期、地點、頭數與選填車次簡寫；原完整備註仍在歷史資料。
3. 正式環境`FEED_AUTO_ALLOCATION`改為`equal`。明確指定共用桶各棟批次時，依涵蓋棟舍數平均分配，不使用頭數權重：1、2棟共用桶2噸，各棟1噸；2001公斤各1000.5公斤。已人工確認的原分量優先保留。沒有明確可歸屬批次仍待補，不亂塞到新批。實體料桶庫存仍只增加整桶一次，實際耗料不憑分攤推定。
4. 每週「售出數」改為逐次數字，例如50、60；同日同批同地點同車次仍合併一車，各原始分棟紀錄不合併寫入。大量逐次數字會換行及續頁，不裁切。底部合計仍用於核對。
5. 全場總覽增加「已清空／已結束紀錄」：存欄歸零的原批次自動出現在這裡，不必刪除棟舍或先改狀態。提供原批次完整歷史與A4直接入口，唯讀帳號也能查看。
6. 首頁總數與各批現況改用`current_farm`：僅飼養中、已進場、剩餘頭數大於0的批次；存欄不明的飼養中批次保留待補。清空、結束與未來進場批次不加入現況出豬、死亡、育成率分母。一般週期統計的原`cumulative`、歷史紀錄與報表維持完整生命週期，沒有刪除舊資料。

主要修改：`app/feed_allocation.py`、`app/server.py`、`app/static/app.js`、`app/static/compact.js`、`app/static/weekly-report.js`、`app/static/weekly-pdf.js`、`app/static/style.css`，另有版本／快取標記、文件及相關測試。資料庫結構仍為4，沒有新增表格、遷移或重寫正式農場資料；平均分量與現況均從原紀錄推導。
