# PigLedger 1.8.1：每次秤重的A4表單與CSV

原列印直接縮印作業卡片，含操作欄與長篇來源文字，手機匯出字太小。本版使用獨立報表：基本資料、分欄個別重量、樣本頭數、欄均重、本次加權總平均與計算說明。來源及操作紀錄保留在原App，不放入列印表格。

每次保存經伺服器成功回應並更新資料後，顯示當次匯出按鈕；歷史作業可再次匯出。同日期不同次或不同棟分開，不受當前歷史查詢排除已保存日期的影響。CSV含UTF-8 BOM、完整數值、個別重量分欄，處理引號及試算表公式字首。快速總重方式不編造個別重量；空白不算0。進場資料明示使用目前批次設定。

## 本地及模擬

- `sh scripts/check.sh`：233項既有單元／整合測試及7份JavaScript語法檢查通過，包含本地SQLite及模擬Hrana。沒有新增資料庫結構或改動頭數／ADG／FCR規則。
- `tests/weighing_report_browser.py`：8組真實Chromium／隔離SQLite／HTTP情境通過，包含實際CSV下載及Chromium生成PDF。使用人工產生的六欄36隻測試樣本，總重1800公斤、均重50；基本資料、各欄重量正確，排除另一棟及長篇來源備註。測試檔不包含使用者照片的實際逐隻重量。
- 合成快速輸入與個別秤重混合：2隻100公斤＋4隻240公斤，總均重56.67，CSV保持原樣本與總重。失敗儲存不出現成功匯出；重試才提供已保存作業。同日另一次不合併。
- 獨立列印只顯示報表；六欄36隻產生一頁A4 PDF，`pdfinfo`核對尺寸與頁數，並轉圖檢查字體及欄位。列印字級不受App大中小影響，不印按鈕或操作頁。PDF透過瀏覽器列印另存，非伺服器PDF服務。
- 4種寬度×2語言×3字級，共24個報表預覽版面無整頁水平溢出；手機只有重量表格可橫向查看。三輪語言、背景同步及匯出操作保留下一筆草稿。
- 唯讀可下載既有作業，不能保存；切換帳號清除上一人的當次匯出提示，帳號雜湊不變。未出現未捕捉JavaScript錯誤。
- `tests/redesign_browser.py`：10組原秤重、作廢、統計、重送及權限回歸通過，列印檢查改驗新的獨立報表。
- `tests/pwa_test.py`：5項快取更新與草稿保護檢查通過，新報表程式包含在版本化資產清單；API與匯出內容不放入離線資產快取。

## 正式資料與驗收界線

改動前已在原Turso保護區備份70筆records、4個帳號、12筆秤重與110筆操作紀錄；保留19、20棟各350進場頭數及12筆照片補登。schema4、原Vercel專案及正式網址沿用，不搬移／重新匯入農場資料，也不重設帳號。

部署驗收使用正式HTTPS資產內容與雲端資料重新讀取比對；詳細結果保存於私密維護驗收檔。雲端驗收不永久寫入測試資料。使用者真實密碼互動登入、Safari、實體iPhone／Android、系統分享與實體印表機仍待使用者驗收；不能以Chromium視窗或生成PDF取代實機結果。
