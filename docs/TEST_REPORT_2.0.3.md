# PigLedger 2.0.3：來源資料核對與封存提醒修正

舊版肉豬工作表的異動週欄為W:AU（10W至34W），AV是APP+PR施打日期。原讀取器掃到AV以後，將日期序號誤當異動量。新匯入限制異動欄範圍，已存在的快取報告亦以相同規則讀取；原Excel、快取原值與來源位置保留，不永久刪除。

封存批次本來就沒有目前在養批次ID。原資料已有明確棟舍與日期時，不再僅因缺在養批次ID列成未分配；缺日期、多棟無分配或均重缺樣本等限制仍保留。沒有建立虛構舊批次，也沒有補猜日期、分攤重量或推算進場數。

舊備份仍檢查原檔SHA及原報告內容；核對報告時容許先前誤列的非異動欄位，還原保留原報告並採正確的讀取規則。新舊備份都不能使疫苗日期再次成為死亡紀錄。
