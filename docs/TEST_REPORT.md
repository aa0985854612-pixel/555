# PigLedger 1.0.0 測試報告

執行日期：2026-10-13。資料全部為隔離的合成農場資料，**不是正式農場、使用者帳號或實機營運驗收**。

## 實際執行結果

- Python 自動化：**40項通過，0失敗、0跳過**。命令 `./scripts/check.sh`；另包含 JavaScript 語法檢查。涵蓋純計算、真實 SQLite 交易、ThreadPool 並發、真實 HTTP登入／CSRF／權限／CSV及 schema 遷移。
- Chromium：**17個操作情境通過**。實際瀏覽器操作本機伺服器，合成資料；涵蓋語言、輸入、焦點、閱讀位置、儲存、連按、回應遺失重試、重開後待送資料、篩選匯出、衝突、離線、六頁響應式、唯讀伺服器拒絕與同瀏覽器切換帳號的角色重載。沒有未捕捉JavaScript錯誤。
- PWA：**5項檢查通過**。實際Chromium Service Worker生命週期，但以暫存副本模擬舊0.9.0→新1.0.0快取版本，並非已發布舊版的真實升級。驗證未保存輸入阻止切換、更新後旧快取清理、API不快取及PNG圖示規格。
- Docker／HTTPS：**8個情境通過**。實際映像建置、Compose、Caddy、可信根憑證驗證（沒有停用TLS驗證）、Secure/HttpOnly Cookie及HSTS、登入寫入、FCR 2.5、備份及容器重啟資料持久性。測試專案使用獨立volume及localhost本機憑證，不是公開正式網址。

## 可重跑

```sh
./scripts/check.sh
python3 tests/browser_smoke.py
python3 tests/pwa_test.py
```

瀏覽器測試需要 Playwright＋`/usr/bin/chromium`；這是測試環境依賴，正式應用無第三方Python依賴。版本程式包已解壓到另一個暫存目錄，從包內來源重跑40項測試亦通過；ZIP完整性及排除資料庫／密碼檔案已檢查。原始情境清單在[瀏覽器結果](evidence/browser-results.json)、[PWA結果](evidence/pwa-results.json)、[Docker結果](evidence/docker-results.json)。

Docker測試請只在專用、沒有正式資料的 `pigledger-smoke` 專案執行：依 `tests/docker_smoke.py` 說明先啟動Compose及複製本機公開CA。該測試建立合成測試帳號及資料，不可對正式volume執行。正式驗收使用自己網域與帳號另外做。

[桌面截圖](screenshots/desktop-1.0.0.png)／[手機截圖](screenshots/mobile-1.0.0.png)是完成多筆測試操作後的合成資料，數字與最初825範例不同，不代表正式資料。

## 模擬與尚未驗收

模擬：斷線與回應丟失、第二操作者更正、合成批次與秤重、0.9.0→1.0.0快取版本。實際程式、資料庫、瀏覽器及HTTP都確實執行；沒有假測試結果。

尚未驗收：使用者正式主機／網域公開部署、實際iPhone/iPad Safari和Android Chrome加入主畫面／長期背景行為、真實豬群抽樣代表性、正式資料與帳號還原、跨主機災難復原、長期營運負載與高可用。沒有既有正式系統，因此也沒有舊系統真實資料迁移驗收可宣稱。未提供耳號時不能辨認人員另建紀錄是否為同一實際豬隻，需依現場事件紀律；同請求重送則由識別碼與交易保證去重。
