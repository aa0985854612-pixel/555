# PigLedger 1.8.3：A4直式每週摘要

每週紀錄表改為A4直式、8mm頁邊，每13週分區；列印只保留基本資料、每週死亡／正常出豬／淘汰／叫料量、期間合計與累計育成率。週齡表頭精簡為11W等，起始日與計算依據保留。

逐日異動摘要、長備註與完整待補清單留在螢幕預覽、CSV及原歷史；紙本明示完整明細的位置，有待補時列筆數，對應數字仍顯示—。不刪資料、不丟週次、不用整頁縮放強迫塞一頁。一般批次優先單頁，超長範圍可自然續頁。

## 驗證

- 真實Chromium／隔離SQLite／HTTP報表情境通過，實際產生短期與39週報表PDF；以pdfinfo核對兩份皆1頁、A4直式（寬小於高），轉圖檢查三個13週分區與數字未截斷。
- 每週數字、合計、育成率、CSV完整異動、唯讀匯出、未登入拒絕、條件改變需重新產生，以及24種手機／語言／字級版面沿用報表瀏覽器驗證。
- 原秤重匯出8組瀏覽器回歸、PWA更新與草稿保護5項檢查，與每週報表計算單元測試一併驗證；資料與計算程式未修改。
- 修改前保護區備份70筆records、4個帳號、12筆秤重與110筆操作紀錄。正式HTTPS版本與資產重新核對，原Turso資料及帳號指紋維持一致；無schema更新或環境變數變更。

CSV不包含Excel紙張方向設定；直式單頁格式適用列印／透過瀏覽器另存PDF。實體iPhone／Android、Safari、印表機及各裝置列印頁首頁尾仍待驗收，不能以Chromium產生PDF當作實機通過。
