# PigLedger 2.0.1：棟舍廠商與叫料自動帶入

棟舍新增可選feed_vendor（養全／新農科）。管理員設定，伺服器檢查角色、值與revision；舊客戶端未傳新欄位時保留既有值。使用原schema4、原ID、六頁及正式網址，不重建資料庫。

飼料主表單直接選棟，自動帶入該棟預設廠商、篩出相符料桶；唯一在用桶自動帶入，雙桶需選號。沒有棟舍預設時沿用桶廠商；本筆廠商可修正。共享桶不產生分棟公斤，共用棟預設不同時提示核對。修改預設不回寫舊紀錄，週表分開列預設及已登記廠商。

## 已驗證

- 本地345項單元／整合測試及11份JS語法檢查通過。新增8項覆蓋SQLite及模擬Turso：廠商設定／舊客戶端保留／revision衝突、錯誤值及管理員限制、改設定保留舊訂單及其他棟、含新舊欄位的備份還原。
- 真實Chromium＋本地HTTP／合成資料11組料桶情境：設定廠商後自動帶入、單／雙／共用桶、不同廠商提醒、三輪語言與同步保留、歷史編輯、CSV與直式一張A4、24種尺寸／字級／語言無整頁橫向溢出、唯讀直接API403。
- 原叫料13組回歸含斷線成功回應遺失、重載及重試不重複、實際FCR不變；PWA5項更新與草稿保護通過。
- 真實Turso預演24棟廠商補值、逐筆稽核後ROLLBACK，再重新連線核對全部原資料不變。正式套用前另備份，只補未設定且現有在用桶廠商一致的棟；既有預設優先保留、不改桶設定或舊訂單。沒有SQL結構更新。
