# 2.0.23 — 飼料一次登記多筆

在既有叫料表單加入「本次清單」。選一次日期後逐筆加入，數量預設噸、料別仍選填，保留原有廠商帶入、預計批次及共用桶分量。可取回修改、取消修改及移除；未送出清單依帳號保存在同一裝置。核對畫面一起列出歷史同日同桶及清單內重複，明確選擇更正原紀錄或另筆新增後，一次完成交易。任何錯誤整張回復；過期預覽與重複目標拒絕寫入。同一儲存請求重試不重複新增，成功回應後才清空清單。
