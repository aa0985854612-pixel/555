# 2.0.29 工作行事曆

新增獨立的每週固定／單日臨時工作，依農場日期自動整理星期一到星期日。採用既有版本檢查、作者權限、操作歷程及可重試的寫入佇列；不更動畜牧資料。沿用SQL schema 4 的通用 records 資料表，無資料庫結構變更。

驗證：

- `sh scripts/check.sh`：556 個單元／整合測試通過；17 個 JavaScript 語法檢查通過。
- 行事曆測試分別在SQLite與模擬Turso執行：跨年、閏日、星期日、起迄日包含邊界、停用工作、單日工作不重複、時間排序、欄位驗證、作者權限、版本衝突、冪等重試、完整備份還原及畜牧／帳號資料隔離。
- `python3 tests/work_calendar_browser.py`：11項通過。實際手機新增、更正、停用、前後週、登入與CSRF、遺失成功回應後重整並重試、唯讀與作者權限、中越文、大字320/390/768px、七分頁可到達；瀏覽器無JavaScript錯誤。
- 實際下載PDF以 `pdfinfo` 驗證一張 595.28 × 841.89 pt 直式A4；檢查七天及完整工作備註的繪圖內容，預覽直接使用PDF嵌入的JPEG。已檢視PDF轉圖版面。
- 文字過量時逐行保留至同一週的編號續頁；測試18項密集工作及各自備註皆完整，無省略。

行事曆以空白資料上線，不在正式資料庫加入測試工作。舊版程式不認識新 work_tasks 類型，建立工作後請使用2.0.29或更新版本還原完整備份。
