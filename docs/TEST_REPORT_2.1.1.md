# 2.1.1 · 藍色介面、週表優先與統一備註

使用者指出原A4下方各棟字級與間距不一致，上方週表反而被壓得太小，並明確要求藍色。

## 變更

- `app/static/design-system.css`：主色改為`#234f83`，按鈕、導覽、焦點、提示與輔助背景同步改藍色／中性色。A4預覽標題縮為次要文字，列印提示與其他內容對齊。
- `manifest.webmanifest`與`index.html`：手機／PWA主題色改藍；識別、圖示、scope及網址保留。版本及Service Worker快取升為2.1.1。
- `weekly-pdf.js`：取消各備註區獨立放大至13.5pt及拉開到框底的間距。全部死亡／出豬共用字級，最多8pt；一般單行筆距12pt，多行亦使用同一行高及段距。資料密集時一起縮小備註，不各區各自調整。
- 先保留上方週表正常字級及原宣告列高；僅週表本身內容已過密、無法容納最低備註區時才縮排週表。備註先利用同區域右側欄，維持原順序；各棟按內容分配寬度，保持獨立標示。左右備註的首筆日期對齊。
- `weekly-report.js`同步更新中越語紙本說明，資料模型與計算不變。
- 固定一頁A4、每筆完整、同車出豬分組、平均分料、未來資料、無CSV及紙本不印淘汰規則不變。沒有後端、API、資料庫結構或正式農場資料修改。
