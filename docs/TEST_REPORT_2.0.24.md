# 2.0.24 — A4備註使用實際剩餘空間

取消死亡每棟6筆、出豬12筆的固定限制。以實際字體量測備註行數和頁尾高度，備註依內容增高；需要時適度調整字級、出豬欄內的排列及分棟列數。死亡仍在左側按棟舍排列，出豬仍在右側；長備註換行保留文字。正常內容優先完整列出，僅真正超過一張A4容量時，才標示準確的未列筆數及CSV提示。上下週期表、叫料逐筆一行、合計及存欄計算保持原有內容。
