# PigLedger 1.7.0 批次分組與手機總覽測試

設定以現有穩定批次鍵分組，保留每棟原始ID與進場日期。同名不同日期分開，群組只用於呈現，不合併資料、補數字或修改全批。按棟更正時移動原本表單，不重建輸入；頭數及均重可直接填，其他設定展開，保存仍經伺服器權限、來源分母與修訂衝突檢查。

每日登記保留為預設頁面。全場總覽可收起表單，顯示全場摘要及按批次整理的各棟存欄、累計死亡、育成率；未知資料保持—及可展開原因。累計死亡不是選定期間死亡，日期區間仍由週期統計查詢。手機雙欄篩選、原字體偏好、繁中／越南語、紙本秤重與作廢保留。

## 正式雲端與資料保留

修改前以原生產環境權限檢查當時正式版本1.6.4、schema4及正式庫，新增持久雲端備份；當時58筆records、4個帳號，使用者最新更正均在備份內。備份不公開打包。

本版只更新程式與介面，沒有資料庫結構、環境變數、Excel、密碼或帳號更新。推送原main，由原Vercel專案自動部署。部署後以受保護環境確認正式HTTPS health、首頁、compact／redesign／CSS、manifest／圖示及SW版本，並以原Turso唯讀交易核對資料、帳號與安全狀態指紋；不新增測試農場紀錄或重設帳號。維護程式排除在函式包外、建置後移除，完成後清理臨時維護部署並驗證正式網域綁定Git部署。

尚未驗收：實體Android／iPhone／平板觸控、各手機內建日期選單及實際行動網路；使用者目前密碼的正式網站互動登入未代測。正式HTTPS資產及真實資料保留檢查不等於手機實機操作驗收。保留原安裝圖示1.6.3檔名，程式及SW更新至1.7.0。
