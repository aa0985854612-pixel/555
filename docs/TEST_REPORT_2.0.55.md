## 資料與部署限制

所有資料驗收使用隔離合成農場，不在正式資料庫新增假豬、假到料／叫料或假庫存基準；既有批次、頭數、飼料、秤重及使用者保留。物理料桶庫存需要管理員輸入真實盤點基準與容量才啟用；未設定不當作0。有未歸屬的到料、跨日實耗、或多桶不明時顯示資料不足，不能宣稱已測得現場剩料。記錄到料也不代表自動知道已消耗量。

發布沿用原GitHub→Vercel整合，核對新提交對應READY及原三個正式別名、上午10點cron。沒有額外臨時驗證部署，沒有更改資料庫環境憑證或啟用LINE／OpenAI。正式服務的HTTP直連受目前環境限制，部署證據為Vercel原生READY、提交及別名核對，不把本機測試描述成已在真實農場輸入測試資料。
