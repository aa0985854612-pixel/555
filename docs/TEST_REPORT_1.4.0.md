## 真實雲端執行

在既有 Vercel 受保護建置環境，使用原敏感 Turso 金鑰（沒有讀出該金鑰），已完成：

- 更新前持久雲端備份，另以公開憑證加密取回私密離線備份並驗證內容。
- schema3→4只增加account_security，先保留舊標記相容部署交接，再完成標記更新；更新交易核對原資料內容一致。
- 新工作簿預覽、對照、保留人工差異、重複來源匯入略過，無新增棟舍／批次或重複日常異動。
- 原使用者資料逐欄一致，原紀錄保留；只有一筆來源可靠的缺漏入場均重補登，增加版本及操作歷程。
- 另外建立三種角色，原同名帳號不覆寫。原farmadmin未重設。
- 新後端與真實Turso的回送HTTP驗證：原管理員登入／登出、三輪快照與未變更游標、歷史日期統計、死亡篩選與CSV筆數、來源均重不偽造頭數、帳號存在、唯讀／未改臨時密碼伺服器拒絕。

以上是 Vercel 建置內的回送HTTP＋真實Turso，**不是正式網址HTTPS瀏覽器驗收**。驗證用敏感環境變數已移除；一次性建置輸入執行後移除，亦排除在函式包外。日常使用無須上述維護環境。
