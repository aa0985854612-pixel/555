# 出豬即時存欄預覽

登記正常出豬或淘汰時，選擇棟舍、批次、日期並輸入頭數，表單直接顯示目前存欄、本次出豬、出完剩餘。例如159頭出80頭後，預覽為79頭。選擇的批號、棟舍、目的地與計算日期會顯示在同一區。

預覽使用現有授權GET /api/statistics的單一批次、登記日存欄，包含已登記的當日異動。更正時先移除原筆紀錄對該棟、該日期的影響，再套用新的出豬數量。原筆尚未發生時不回補，切換棟舍也不回補到別棟。儲存仍通過現有伺服器存欄、權限、版本與重複紀錄核對。

- 超過存欄會顯示負數及提示，阻止表單直接提交。
- 缺少頭數、存欄未知、日期早於進場日、網路失敗，各自保留明確提示；不將未知填成0。
- 切換棟舍、批次、日期、數量、語言及取消更正會更新預覽。舊請求延遲回覆不會覆蓋目前棟舍。
- 預覽不新增、修改或刪除農場紀錄。登出會清空預覽。
- 手機直排大字與較寬畫面橫排，支援繁體中文、越南文。

驗證：scripts/check.sh完成556項單元與整合測試及JavaScript語法檢查；outgoing_preview_browser.py通過9項真實HTTP/Chromium情境；movement_review_browser.py通過5項原有更正與重複核對情境。所有測試使用隔離的合成資料，未連接正式資料庫。手機範例位於artifacts/outgoing-preview-mobile.png。
