# PigLedger 2.0.9：上下兩排、留白與固定A4 PDF

針對用戶實機仍印兩頁、日期與零值換行的回報，週表改成兩個等欄寬區塊。通常每排13週，27～40週的範圍分成兩個較長區塊；第二排不足欄位留白。日期使用月／日，不再顯示0、0.000或替未知值填數字。未知仍保留待補來源，空白不是確認無死亡。

新增「下載 A4 PDF」：使用當前已授權報表在本機畫出固定A4頁，封裝為高解析影像PDF，不經手機網頁分頁、不帶瀏覽器網址及日期頁尾，不新增伺服器依賴或資料寫入。完整可搜尋文字與逐筆資料在CSV。過長單格明確標記「… CSV」，不假裝全部塞入；超過40週分頁，不省略週數。原瀏覽器列印入口保留且明確標示。
