# PigLedger 2.0.60 — 清楚、乾淨的日常版面

依使用者要求移除「智慧快捷紀錄」與「工作行程表」的前台功能。首頁不再建立快捷輸入框／快捷歷史；不載入快捷、行程表及行程表PDF相關資源，不建立行程頁。手機六個分頁同時可見：每日登記、週期統計、歷史紀錄、飼料紀錄、秤重紀錄、設定。舊行程連結回到每日登記。

首頁直接使用原豬隻表單，縮小次要標題與外部回報連結；地點／車次集中在既有選填區，已登記地點的更正會展開該區。出豬剩餘預覽只在日期、批次和有效頭數填好時出現，以緊湊三欄顯示；空白與儲存後不留占位卡片。超量、未知存欄與網路失敗原檢查保留。

## 資料與相容性

- 不刪除任何已登記豬隻、飼料、秤重、工作及稽核資料，不新增schema或搬移資料。嘉得叫料即到料規則維持1。
- 舊快捷建立的豬隻／叫料繼續由原表單更正、原作廢流程刪除。舊快捷到料使用原到料表單及精簡的「核對到料更正」視窗，保留容量確認、原ID與噸／公斤單位，不會回到已移除的智慧輸入介面。
- 保留後端與原來源metadata供歷史、更正、備份、既有待重試請求使用。缺少已移除表單的舊請求仍能同鍵重試，成功回覆不因找不到表單而報錯。
- 共用桶分量未知的前端實耗保護移到基礎計算；不因移除快捷模組而把未知分量算成0。通知金鑰、裝置狀態、伺服器10:00提醒及其它資料邏輯不變。

## 修改檔案

`app/static/index.html`、`sw.js` 移除前台功能載入及快取清單；`app.js` 移除行程導航、保護舊待重試與共用桶計算；`compact.js`、`style.css`、`outgoing-preview.js/.css` 整理導航、字級、選填與出豬預覽；`bin-stock.js` 保留共用的庫存文案及樣式；新 `delivery-review.js` 僅處理舊到料原表單更正。其餘為2.0.60版本、操作文件、語法檢查與既有測試的選填區操作更新。
