# PigLedger 1.7.3：照片式週期死亡清單

週期統計改為同一張精簡清單。上方是查詢日期、範圍及期間死亡合計；每列是同批棟舍、截至查詢日的可靠週齡、批號與進場日、各棟死亡及該批合計。按週齡由高到低，未知週齡置後；零死亡直接顯示，不再收在另一個展開區。保留深藍、繁中／越南語及Aa字級。

日期、全場、跨棟批次、單棟及整組沿用原查詢。已結束棟舍納入相關期間，未進場批次不顯示假零；同名不同進場日不合併。原育成率、存欄、飼料、ADG及FCR仍在其他統計中。沒有SQL結構、資料匯入、帳號或密碼變更。

點整批／單棟數字會保留已顯示結果的日期與範圍，不使用尚未送出的新日期。歷史與CSV仍走原篩選邏輯。補上分組限制，避免同批別組死亡混入；日期未知的死亡保持資料不足，即使已知所屬單棟也不當成確定期間數字。其他已知單棟不被無關棟舍的未知紀錄影響。查詢區間有舊表死亡時，在清單保留來源歷史列；未知週齡不猜測，並不建立新庫存或批次。

## 本地實際執行

- `sh scripts/check.sh`：215項單元／整合測試、5份JavaScript語法檢查。新增10項日期、分組、單棟、來源未知、舊表歷史、已結束棟舍及合計與歷史一致的測試。
- `tests/period_deaths_browser.py`：7組實際Chromium／隔離SQLite／HTTP情境；11批、24棟合成資料。驗證期間合計、各棟分配、零死亡直接可見、週齡排序、同批出清棟舍、起訖日期、明細及CSV、保留分組與單棟批次、唯讀查詢及資料／帳號雜湊不變。
- 同測試涵蓋320、375、390、430、768及1440px，繁中／越南語、小／中／大字，共36種版面。無整頁水平溢出；每列及單棟入口至少44px點擊高度。在390px繁中／中字，合成清單每列約125px，11列約1378px。批號及日期仍保留，沒有為縮短清單隱藏零死亡。
- `tests/appearance_browser.py`：9組字級、閱讀層次、草稿與同步回歸，含144種六頁版面。死亡總數大於頁標題、一般內容及來源日期。
- `tests/redesign_browser.py`：10組秤重加權、失敗重送、作廢預覽、來源保留及角色限制回歸。
- `tests/pwa_test.py`：5項快取更新、未儲存內容保護及API不快取等檢查。

瀏覽器資料全部是合成測試資料。報告中的「8隻、26W」等示例來自合成資料，沒有當成正式農場紀錄。

## 模擬與尚未驗收

手機／平板／桌面尺寸是Chromium視窗及觸控模擬，不是實體iPhone或Safari。缺資料畫面另以明確標示的API結果模擬，確認—及已知小計，不聲稱該模擬是雲端資料。

Safari/WebKit及實體iPhone仍待驗收；既有環境的官方WebKit下載受網域限制，本版未宣稱Safari、iOS原生選擇器或實機鍵盤通過。正式使用者互動帳密登入未代測，不重設帳密。

## 正式備份與部署驗收方式

修改前已建立原Turso持久備份，58筆records、4個帳號；農場資料、帳號及安全設定指紋未變更。原main、Vercel專案、固定HTTPS網址及Turso沿用，原來源Excel與已確認的人工資料保留。本次沒有農場資料寫入或資料庫遷移。

部署驗收核對正式HTTPS版本、新版介面與快取資產；在原Turso唯讀交易測試兩個日期區間、全場、各批次及各棟，核對死亡清單合計、來源歷史及既有育成率。前後指紋需相同；維護程式排除於正式函式包，臨時維護部署清理後，固定網域指向Git正式部署。具體部署、套件完整性與唯讀檢查結果另存維護驗收檔。
