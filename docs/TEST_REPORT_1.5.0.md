4. 新檔未包含舊歷史工作表；仍保留前版來源的舊表歷史。來源異動投影564筆、來源均重38筆，另保留原6筆日常異動；投影筆數不等於新入帳筆數。缺日期、單棟分母或樣本頭數者繼續待補。

## 待驗收與限制

維護環境到正式網址的直接HTTPS連線仍有網路代理限制；公開網址登入、正式網址部署後瀏覽器重讀、Android／iPhone／iPad實機、行動網路、跨裝置多人操作與加入主畫面仍需現場驗收。本版Docker容器及Windows雙擊未重跑。

紙本照片用作版型與操作參考，沒有把辨識不明的數字自動入帳。表內來源均重沒有樣本時不編造個別重量；合併批次入場數不當成單棟分母。

來源作廢若缺可靠日期／棟舍而無法修正基準存欄，伺服器會阻擋並說明；已用作批次入場均重的來源，須先更正該入場均重再作廢。重要操作保留原因、前值與影響摘要。舊版1.4不能處理新來源作廢類型，請用1.5以上程式還原本版備份，不直接回滾舊程式或覆蓋正式資料。
