# PigLedger 2.0.57 — 飼料頁面精簡

未設定或未使用的功能不再佔用日常操作畫面。

- LINE 連線資料未填且沒有已綁定群組時，隱藏整個 LINE 設定入口；每日飼料登記改用不提 LINE 的說明。只讀取狀態，不啟用 LINE 或任何 API 辨識服務。已有綁定但連線資料失效時仍保留管理入口，避免無法解除原綁定。
- 沒有正式到料紀錄時，隱藏空白到料卡片；有資料後自動出現。若已有資料但篩選查無結果，保留原篩選空狀態。
- 料桶庫存沒有啟用時不顯示庫存區，也不請求空庫存清單。已啟用時只列啟用庫存的料桶；原料桶管理仍可設定容量與庫存基準。
- 每日飼料登記預設收合成一行。有待確認清單或新清單同步進來時自動展開；手動新增、歷史清單、照片核對與原權限保留。確認儲存流程與正式叫料資料不變。

## 修改

`app/static/line-feed.js`、`app/static/feed-drafts.js`、`app/static/bin-stock.js` 為本次行為修改；其餘為 2.0.57 版本、快取、操作文件與現有瀏覽器測試定位流程更新。無後端邏輯、資料庫表、schema、資料遷移或歷史資料刪除。

## 驗證

使用既有的真實 Chromium／HTTP 測試和隔離合成資料：

- LINE：6 項情境，包括未設定時不顯示、已設定的測試環境仍能管理、照片只入待確認、唯讀權限、中越語及 320／390／768／1440px。
- 照片待確認：8 項情境，包括修改、勾選確認、正式叫料更新、不採用、重新載入後保留、斷線重試與帳號隔離。調整測試讓無待確認資料時先點開收合列，操作功能未刪除。
- 原智慧快捷紀錄：16 項情境，包括到料自動出現、已啟用庫存仍能查詢／設定、庫存回算、共用桶與多人同步。
- 修改的 JavaScript 語法檢查及 `git diff --check`。

共 30 項瀏覽器情境通過，沒有在正式農場寫入測試資料、發送通知、啟用 LINE 或呼叫付費辨識。此次為介面整理，未重跑未修改的全部後端測試。
