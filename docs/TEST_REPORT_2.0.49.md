# 2.0.49 出豬按日期、目的地與車次合計

肉豬紀錄表在目前選定的單一批次／棟舍範圍內，按日期、目的地、車次及正常出豬／淘汰類型合計摘要。未填車次按空車次分組，未知目的地保留原筆。各筆不同備註去重後一起保留，原始events不修改。A4 HTML、PDF模型與CSV摘要共用outgoingGroups，CSV原始明細保持逐筆並附車次。

新增選填outgoing_trip，正常登記及匯入來源更正均可填，80字上限並拒絕控制字元。僅用於sale／cull，非出豬清除空值。舊用戶端未送車次時保存原值，明確空字串可清除。舊來源更正欄位集合仍合法，新欄位為可選，不遷移資料表。歷史CSV亦輸出車次，保留公式注入防護。車次僅為描述，不影響頭數、存欄、FCR或育成率。

驗證：576項單元／整合與JavaScript語法檢查通過，其中6項車次測試包含一般／匯入來源、舊用戶端、更正、非法值、權限沿用、備份還原、本機與Turso模擬、冪等重試。真實HTTP／Chromium通過6項合併情境：兩棟30＋30為南投60，同日兩車分開，日期／目的地／類型分開，單棟與其他批次不混算；A4為一頁直式，PDF嵌入預覽同一張JPEG，CSV摘要一致且保留11筆原明細，歷史CSV保留車次，報表讀取不修改records。另通過7項原A4 PDF情境（含越南文、四寬度、密集備註、唯讀下載）、9項出豬預覽與5項來源更正／重複核對情境。原PDF測試的登出切帳號加入等待登入畫面，避免導航中止非同步登出。

測試全為隔離合成資料；手機A4預覽已目視檢查。版本與快取更新至2.0.49，通知程式與台灣10:00排程保持。
