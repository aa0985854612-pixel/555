# PigLedger 1.7.2：iPhone表單與安全距離

使用者iPhone照片顯示：日期「2026年10月16日」在半寬欄位內擠到異動類型。原版僅驗證Chromium尺寸不足以證明iOS原生日期控制項正常。本次將手機日期欄位獨占一列，不縮小文字、不改為自由文字日期；保留原生日期選擇器。

每日登記改為日期全列、類型＋頭數、棟舍＋較寬批號。數量移到類型旁，與實際DOM／鍵盤順序一致。大字級及窄螢幕依需求改單欄，越南語較長的類型使用全列。各頁日期加上明確class，手機日期排版不依賴Safari新版本的`:has`。原提示移到進階內容，讓常用表單與儲存按鈕更容易看到。

統一輸入與選單高度、內距及字重，日期顯示靠左；選單仍使用原生選擇器，關閉時顯示單一下箭頭。設定文字自動調整為100%，仍保留Aa字級與頁面縮放。頁首、底部導覽、字級選單與捲動距離使用iPhone安全區，避免與瀏海／主畫面指示區重疊。沒有變更資料、權限或計算規則。

## WebKit及實機限制

已嘗試安裝官方Playwright WebKit。改用工作區快取路徑解決預設安裝目錄問題後，官方下載仍回覆403 Domain forbidden；取得額外網路連線權限後重試結果相同。`tests/iphone_browser.py --engine webkit`記錄為blocked、0情境執行，不能視為通過。未停用TLS或改走其他來源。

若維護環境日後允許`cdn.playwright.dev`與`playwright.download.prss.microsoft.com`，可使用官方安裝指令並執行同一支測試的`--engine webkit`。原生iOS日期／下拉選單、鍵盤、實體瀏海安全區與主畫面App操作仍待實體iPhone驗收。Chromium手機尺寸與安全區模擬不能代替Safari或iOS實機。
