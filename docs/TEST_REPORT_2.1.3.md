# 2.1.3 · 已結束批次退出一般選單，集中歷史入口

標記已結束的原批次保留在設定與歷史，從一般肉豬紀錄表選單移除；週期統計既有僅列可選飼養中批次的行為保留。新增「歷史紀錄→已結束紀錄」及設定同名入口，搜尋批號／棟舍，直接開原明細、下載原A4或由管理員開啟既有批次管理。展開清單時收起無關的查詢區；查看明細或收合後回到原查詢。

## 程式與資料

- `ended-records.js`：索引原`batches.status=ended`，按原批號歸組，使用原查看明細、A4與管理處理器。保留中越語、角色、查詢輸入與跨裝置更新，登出清除該帳號的清單。
- `weekly-report.js`：普通模式只列active；從歷史直接開啟ended模式。混合狀態的同批，普通報表列仍在養的棟舍，歷史報表列已結束棟舍。每次一般開啟重設模式。狀態改變時重新核對選項、取消過期請求、清除舊預覽與列印內容，避免仍可下載舊範圍。
- `app/weekly.py`：新增選用查詢`batch_status=active|ended`，在原批次ID集合內限縮，並避免其他狀態的飼料或未來日期混入。未提供此參數的舊API維持原完整同批行為；無新資料格式、公式或欄位。
- `compact.js`：首頁已清空區保留仍為active但存欄零的批次；已結束資料從歷史／設定查找。
- `design-system.css`、`index.html`、Service Worker與檢查腳本：加入同一藍色版型、載入與PWA預快取。

schema仍為4，沒有資料遷移、批次搬移、紀錄複製或刪除。結束／重新開啟沿用既有管理員核對、單一交易、修訂衝突與稽核；標記結束不會自行把頭數改成零。週期統計的完整同批歷史、公式與金額／重量原計算不變。單頁A4產生器、均分料桶、未來已登記資料、無CSV、藍色及頂部維修單圖案都保留。
