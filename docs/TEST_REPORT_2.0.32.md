# 2.0.32 行事曆圖片匯出

新增「匯出圖片」：支援檔案分享的手機以真正的JPEG File開啟系統分享選單；不支援時下載圖片，並提供可長按、另開及逐頁下載的完整圖片。直接使用A4 PDF嵌入的JPEG，維持1786 × 2526像素與相同內容。

圖片提前準備，保留原始點擊的user activation；同一週的並行產生共用一個工作，日期／語言／登入身分變更後的舊結果會丟棄。取消分享不觸發下載，也不宣稱已寫入相簿。網站只開啟系統分享，不能略過手機的儲存選項。

驗證：

- `sh scripts/check.sh`：556個單元／整合測試、17個JavaScript語法檢查通過。
- `python3 tests/work_calendar_browser.py`：既有14項通過，A4、七天邊界、固定／臨時工作、權限、斷線重試及手機操作保持正常。
- `python3 tests/calendar_image_browser.py`：12項通過。檢查手機可信點擊的分享呼叫、真正JPEG檔頭與MIME、檔名週一至週日、SHA-256完全等同預覽／PDF嵌入圖片、實際下載1786 × 2526 JPEG、取消分享、分享拒絕、無Web Share、切週競態、分享期間防重複、登出清除、唯讀匯出、多頁完整逐張下載及中越文。
- 匯出／分享／取消不改動任何工作、畜牧、帳號、請求或操作歷程紀錄。

Web Share的檔案交付與失敗分支以瀏覽器模擬原生API驗證；實際相簿選單由手機系統提供，未聲稱已在真實手機上自動寫入相簿。
