# 2.0.65 — 飼料料別記憶、整數噸數及A4最新料別

選棟舍或實際料桶時，從同步的正式飼料紀錄找最新非空白料別，自動帶入並允許更改。依紀錄日期、同日建立時間及ID排序；舊到料紀錄依原批次連回棟舍。共用桶沿用同桶資料，雙料桶依選定桶分開帶入；沒有相關紀錄保持空白。未確認照片與本機未儲存清單不作為來源。背景同步、語言切換、原筆編輯及重試回填不會改寫使用者已填資料。

數量輸入離開欄位時移除尾端小數零，2.000變2、1.50變1.5，保留實際小數重量。清單及核對沿用原精度格式。沒有將用量取整或更改原紀錄。

報表在既有`feed_setup`回傳`latest_type`，只讀取所選範圍的最新非空白料別；A4、PDF及瀏覽器列印的標題欄改為「料別」，只顯示這個值。原`recorded_types`、逐筆資料及CSV歷史料別保留。已登記未來日期照常納入完整報表；截至日期統計及庫存規則不變。

修改檔案：`app/static/feed-setup.js`、`app/static/feed.js`、`app/static/weekly-report.js`、`app/feed.py`；另有版本／快取標記、操作文件、原料桶測試擴充與`tests/feed_memory_browser.py`。資料庫結構仍為4，不增加資料表或欄位，不重寫正式農場資料。
