# PigLedger 2.0.13：死亡與出豬備註左右分欄

每週紀錄表上方保留同批跨棟死亡合計，下方備註分成等寬兩欄：左邊死亡備註列日期、實際棟舍、死亡頭數及原有備註；右邊保留出豬地點與相關明細。死亡只取同一份唯讀查詢的死亡事件，單棟篩選不混入其他棟。缺歸屬資料維持待補，不猜棟舍或補零。

預覽列完整備註，CSV新增逐週死亡備註並保留完整原始事件。直接下載PDF及瀏覽器列印都左右分開；A4摘要每側先列12筆，更多資料分別標明剩餘筆數及完整CSV入口。無資料留白，原週合計、出豬、淘汰、叫料、育成率與計算規則不改。兩排週期、32週及兩預留空欄維持。
