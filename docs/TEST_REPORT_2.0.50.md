# 2.0.50 同日飼料日期只列一次

肉豬每週紀錄表的飼料依原日期排列，同一天首筆為「9/23+2(20)」，後續為縮排的「+2(19)」。不合併或更改原筆數量，料桶識別與未分攤提示保留。各週及進場前叫料分別處理；HTML、PDF與CSV摘要共用feedLines，CSV原始明細保留完整日期。已指定與待分攤的CSV摘要各自保留日期，避免跨欄依賴。

等寬字體及保留空格使一般飼料的加號對齊；同格採一致縮放，長待分攤註記另外限制寬度。進場前叫料改為直排列出。既有A4密集內容的「… CSV」提示保持，PDF嵌入的圖片與預覽完全一致。無資料結構遷移，無正式農場資料寫入，通知邏輯與台灣10:00排程不變。

驗證：576項單元／整合測試及JavaScript語法檢查通過。新增真實Chromium／HTTP的5項飼料日期情境，涵蓋交錯日期、同日多筆與小數噸數、待分攤料桶、進場前叫料、HTML/PDF模型、CSV完整日期、單棟範圍、320/390/768寬度、資料不寫入、單頁A4及預覽JPEG與PDF一致。另通過7項既有A4情境、6項叫料更正與進場前叫料情境、6項出豬車次情境、5項混合進場日期報表情境。既有測試配合半形括號更新；叫料卡片以空白正規化比對數量與單位，不依賴CSS換行；混合日期報表測試先等待預覽並展開完整明細，再讀取可見文字。

所有測試使用隔離合成資料，已目視檢查A4預覽。正式部署另以唯讀HTTP核對版本及發佈資產，不連資料庫或發送推播。
