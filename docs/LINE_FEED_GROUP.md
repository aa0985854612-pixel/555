# LINE 群組照片叫料登記（2.0.54）

LINE群組傳照片→圖片辨識→網站待確認→使用者核對／修改→正式登記。聊天傳照片的舊流程也保留。群組內打「確認」、一般文字或postback不會直接更動叫料；以登入網站的權限、勾選、版本及預覽驗證完成正式確認。

## 第一次連線

1. 在 [LINE Official Account Manager](https://manager.line.biz/) 建立官方帳號，於設定啟用Messaging API，連到自己的LINE Developers provider。需具備該官方帳號與Messaging API channel的管理權限，這一步不能由網站代替使用者登入完成。
2. 在 [LINE Developers](https://developers.line.biz/console/) 的Messaging API channel取得Channel secret、長期Channel access token；開啟Allow bot to join group chats。關閉官方帳號內建的自動回應，避免其他無關回覆。
3. 圖片辨識使用OpenAI API，在自己的OpenAI專案建立API key，需有可使用的API額度。ChatGPT訂閱不等於API額度。
4. 在既有Vercel專案555的Production環境填入三個伺服器環境變數：`LINE_CHANNEL_SECRET`、`LINE_CHANNEL_ACCESS_TOKEN`、`OPENAI_API_KEY`，重新部署使新值生效。這些值不進網站前端、Git、聊天或LINE群組。可選填`FEED_VISION_MODEL`，預設`gpt-4.1-mini`。不需要新增資料庫或改現有農場資料。
5. 登入農場網站管理員→飼料紀錄→每日飼料登記→LINE群組收圖設定。狀態會逐項顯示是否已填變數，這只代表存在，仍需真實連線測試驗證內容及額度。
6. 將網站顯示的Webhook網址貼進LINE Developers：正式網站為`https://555-rho-nine.vercel.app/api/line/webhook`。按Verify並開啟Use webhook及Webhook redelivery（重要：多張圖片、暫時性錯誤及中斷依賴重送）。Verify的空事件有合法簽章即可200，不需要登入農場網站。
7. 邀請官方帳號加入自己的LINE群組，於網站按「產生群組綁定碼」，10分鐘內把完整`綁定飼料 XXXXXXXXXXXX`指令傳進群組。正確指令只能用一次。機器人回覆綁定成功後，更新網站狀態確認。綁定碼請只傳到你要授權的群組。
8. 傳一張叫料照片。機器人列出辨識的日期、料桶、料別、廠商、噸數及待核對提示；按回覆的清單連結，在網站核對完整藥名、時間、備註及新增／更正差異。最後勾選核對並按「確認正確，正式登記」。首次真實照片也遵守先待確認，不能把測試當成正式同意。

## 使用與限制

- 同時只綁定一個群組；同群組內的成員皆可傳照片，待確認清單的建立者歸屬綁定時授權的網站管理員。管理員可在網站解除或改綁，既有待確認／正式紀錄保留。管理員停用或降權後停止收圖，其他管理員可以重新綁定。
- 綁定群組的照片會透過LINE取得並交給OpenAI辨識，會消耗API額度；不匯入一般聊天。僅接受JPEG、PNG、WebP，原圖最多10MiB，每小時最多30個新圖片事件；圖片檔不存入農場資料庫，保留文字轉錄、來源雜湊及狀態。不承諾辨識完全正確，日期、噸數及用藥一定要對照原圖核對。
- 一張圖片最多100筆；可跨日期；日期依正文到料日，不依聊天日期。只有月日、借用收到訊息之年份時要求顯示年份待核對提示；不清楚、跨年衝突留空。模型輸出再次驗證，未知料桶、廠商、料別及數量不猜填。
- 用藥照原文保留kg／ppm，不能推算劑量；圖片中的指令不執行。共用桶只記一筆總量，不猜分攤。卸不下改另一桶的備註不能加另一筆全量。正式確認沿用原紀錄比較與已確認分攤保護。
- 相同LINE訊息重送、辨識成功後失去儲存回覆、同一張照片再傳，沿用同一草稿，避免重複入帳。明確是另一次同量叫料，可由網站新增待確認並核對選擇。若原草稿已不採用／正式登記，同照片不自動重新建立。
- Webhook每次最多辨識一張，避免函式長時間佔用；同批其餘事件依LINE的Webhook redelivery續處理。暫時性辨識或網路錯誤最多三次嘗試；無可靠回覆時，先在網站「最近收圖狀態」及待確認查看。失敗可重新傳清楚圖片或手動新增待確認。LINE重送的時間由LINE控制，不能保證即時。
- LINE回覆失敗不回滾已存的待確認；網站會顯示回覆失敗提示。若原辨識失敗、超出限制或LINE不再重送，不能把它當成已登記，請重新傳送或手動處理。
- 正式確認仍在既有`feed_drafts`交易裡新增／更正`feed_orders`。LINE收圖沒有呼叫正式確認的路徑。群組訊息與圖片不能繞過網站登入、角色及版本檢查。

## 維運

LINE簽章以原始HTTP body的HMAC-SHA256核對，僅這個Webhook使用LINE簽章取代瀏覽器session／CSRF。設定API仍需管理員登入與CSRF，僅回傳環境變數是否存在，不回傳實際值。Webhook來源僅接受已綁定groupId的雜湊；不處理私訊、其他群組、一般聊天或外部圖片網址。

沿用現有requests資料表儲存綁定狀態、事件租約、去重及重試結果，使用獨立namespace並歸屬實際存在的管理員；不改SQL schema版本4，不遷移正式農場資料。這些整合資料不放進一般client snapshot，管理員才能讀取有限的最近狀態。綁定碼只保留雜湊及到期時間，不保留原始groupId、LINE userId、replyToken、圖片檔或服務金鑰。已存草稿在標準備份內保留。

正式部署成功代表程式已上線；三項環境變數、LINE官方帳號權限、Webhook啟用、重送及群組綁定完成，才能真的從LINE收圖。本版本交付時缺少三項正式環境變數，因此未對真實LINE或OpenAI傳圖／發訊，不能宣稱已完成群組連線或辨識準確度驗證。
