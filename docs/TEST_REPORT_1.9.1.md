# PigLedger 1.9.1：登記／總覽分頁與全部無死亡回報

每日登記左側只保留輸入與當日核對；右側全場總覽集中存欄、死亡、育成率、各棟批卡片與最近異動。切換不重建表單，不清空日期、棟舍、批次或尚未儲存的輸入。

當日核對提供一個「全部回報無死豬」入口，按所選日期取得伺服器預覽，列出本次棟批與略過原因。只確認在養、已進場、來源基準日之後、當日無已知或待分配死亡、尚未確認的棟批。已確認、有死亡、來源不明、未來／基準期間及編輯者無權處理的他人舊確認不自動覆蓋。死亡只照原流程登記，不回寫成0。

全部回報採單一交易保存各棟獨立daily_checks、逐筆稽核及冪等收據；中途失敗全部回滾。預覽綁定日期、操作者、角色與棟批／確認狀態；有人新增批次、補登死亡、更改確認等情況會要求重新預覽，不能默默擴大或更改回報範圍。相同key重試回傳原結果，不重複入帳；撤銷及補登死亡的原有保護保留。

## 驗證

- 305項單元／整合測試與10份JavaScript語法檢查通過。新增22項bulk測試（SQLite11＋模擬Turso HTTP11），涵蓋全棟保存、死亡／已確認略過、來源不明、未來／已結束排除、預覽後變動、同鍵並發重試、不同key重複、防止部分寫入、角色與原建立者、撤銷後沿用原ID與revision。
- 真實Chromium＋本地HTTP＋合成資料9組每日核對情境：左右頁籤內容確實分開、一次回報兩棟並各自保存、撤銷後重新回報、模擬成功回應遺失後同鍵重試、補登死亡自動撤銷確認、資料補正及唯讀直接API403。三輪輸入／語言／同步／儲存保留狀態，每輪只寫入一次。
- 10組compact情境（含24棟及144種尺寸／語言／字級／頁面組合）、7組iPhone尺寸／觸控／safe-area、10組週表與A4直式／單頁／CSV、5項PWA快取與草稿保護回歸通過。
- 真實Turso另使用正式bulk函式，將該次測試連線的COMMIT改為明確ROLLBACK，驗證全部候選棟批與稽核／冪等SQL可執行；重新連線核對原紀錄、帳號、audit與requests完整不變。沒有提交測試巡場，也沒有代農場回報真實巡場。
- 原正式網址、GitHub main、Vercel與schema4沿用；先做私密Turso與原始碼備份，部署後核對正式HTTPS資源與未登入API限制。

未完成實體iPhone／Android、Safari、實體印表機及以客戶密碼互動登入驗收；尺寸與觸控模擬不代表實機。正式檢查及部署收據保留在私密維運目錄。
