# 2.0.26 — 週期統計只列在養批次

跨棟批次選單以至少一個同批棟舍仍在養為條件，排除歷史舊表與整批已結束的批次；單棟批次選單也排除已結束棟批。部分棟舍出完時仍保留整批選項、完整棟舍標示及累計死亡。狀態同步、切換語言與重新登入皆採相同規則。裝置原先記住歷史批次時，只清除週期統計不適用的選項和舊日期；歷史查詢保留全部批次及來源紀錄。

驗證：

- `sh scripts/check.sh`：540項單元／整合測試、15個JavaScript語法檢查通過。
- `python3 tests/active_cohorts_browser.py`：7項真實Chromium／HTTP情境通過，涵蓋舊表、已結束整批、相同名稱不同進場日期、部分出完、單棟選單、歷史明細保留、語言／重新整理、記住舊選項、最後一棟結束後同步移除，以及唯讀查詢。
- `python3 tests/cumulative_deaths_browser.py`：7項自動累計、查詢期間、死亡明細、重新整理及中越文檢查通過。
- `python3 tests/period_deaths_browser.py`：8項期間統計及72組版面／語言／字級檢查通過。
- `python3 tests/pwa_test.py`：5項更新／快取檢查通過。
