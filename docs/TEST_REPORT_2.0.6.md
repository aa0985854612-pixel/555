# PigLedger 2.0.6：週期統計直接顯示換肉率

「換肉率／料肉比（FCR）」改為獨立卡片，位於死亡總數下方、各批次死亡清單之前，不必展開其他統計。顯示所選範圍、現有計算結果、實際比較日期及計算方式。原飼料收合區不再重複顯示合併FCR。

資料不足時顯示「—」並列出原因：有效重量不足、抽樣代表性未確認、實際耗料期間不完整、異動活體重量不足、比較日期的存欄不足，或多批次比較日期不同等。叫料紀錄不當成實際耗料。有效的零耗料仍可顯示0.00。

本版沿用原伺服器FCR計算與查詢條件，不新增飼料輸入、不新增耗料推算，不改帳號、農場資料或資料庫結構。已完成的略過核對狀態保留。
