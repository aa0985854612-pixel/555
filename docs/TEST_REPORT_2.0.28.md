# 2.0.28 — 獨立批次、分次進場明細與報表起始日

批次可設定肉豬紀錄表的預設起始日，保留實際最初進場日；報表起始日不覆寫真實進場資料，仍可手動查較早日期。同棟同批可列多次進場日期、頭數、均重及可靠依據，合計必須等於既有入場頭數。補充明細不會再增加頭數。未知均重留空，預覽、PDF及CSV沿用同樣明細。

驗證：

- `sh scripts/check.sh`：546項單元／整合測試、15個JavaScript語法檢查通過。新增6項檢查涵蓋分次明細、起始日、自訂早期查詢、合計及日期／重量驗證、舊版編輯保留資料、取消同批關聯後保留原紀錄。
- `python3 tests/report_entry_lots_browser.py`：3項Chromium／HTTP情境通過。兩個獨立棟批的報表從同日起，分別列出兩次與一次進場，未知均重空白；兩份PDF皆為一張直式A4，CSV與畫面一致；批次設定可補均重而不增加頭數。
- `python3 tests/weekly_pdf_browser.py`：7項既有上下兩排、空白數量、分棟備註、CSV、中越文及單張A4檢查通過。
- `python3 tests/cohort_link_browser.py`：4項同批歸組、原始進場日期、舊批次保留、週齡／報表及唯讀檢查通過。調整既有測試以展開目前的完整畫面明細，保留原斷言。
- `python3 tests/pwa_test.py`：5項更新／快取檢查通過。
- 私有資料演練：只更新指定兩筆批次設定，原始來源、全部異動、叫料、帳號及全場／各棟頭數維持；同一操作重試不再更新。以實際資料生成兩份獨立報表，兩次進場資料逐筆列出，兩份PDF皆一張直式A4。
