# 2.0.22 — 匯入紀錄更正、重複提醒與實際A4預覽

管理員可在歷史紀錄更正匯入的出豬、死亡、淘汰日期、同批棟舍、頭數、地點和備註，填原因後先核對全場及各棟存欄，再儲存。更正另存為來源覆核資料，不改原Excel或已核對的日期分筆。原始ID、分筆ID、作廢、備份、並行版本檢查與操作歷程繼續生效；分棟依據不足時不猜零值。

出豬、死亡及淘汰按日期、棟批、類型和頭數比對手動與來源紀錄，伺服器在同一寫入交易內再次核對。重複需要明確確認為另一筆；取消保留輸入。確認資料若已變動則要求重新核對。

每週報表預設顯示PDF內使用的同一張A4影像，下載沿用已預覽的PDF。CSV與完整畫面明細仍可查看摘要未放入的資料。切換範圍、語言、關閉或登出時，預覽會重建或清除；快速切換語言不會重用已失效的產生工作。
