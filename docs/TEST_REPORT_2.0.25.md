# 2.0.25 — 選批次自動查進場日至今日死亡

週期統計選跨棟批次或單棟批次後，自動帶入進場日至今日並更新統計。切換跨棟批次會清除上一批的單棟條件。後端在指定批次但未提供開始日期時，也以可靠進場日查詢，避免只算結束日一天。明確輸入日期仍可查自訂期間；全場未選批次的單日查詢維持原有規則。標題區分批次累計與自訂期間，點數字查看的歷史／CSV沿用已顯示的日期範圍。

驗證：

- `sh scripts/check.sh`：540項單元／整合測試、15個JavaScript語法檢查通過。新增6項涵蓋跨棟、已出完棟舍、臺灣日期、單棟、自訂期間、舊表、來源未知及進場前截止日期的情境。
- `python3 tests/cumulative_deaths_browser.py`：7項真實Chromium／HTTP情境通過，涵蓋切換自動查詢、清除舊日期與單棟限制、歷史明細、保留自訂期間、單棟批次、重新整理、中越文及唯讀查詢。進場當日與截止當日均計入，未來死亡和出豬不計入死亡數。
- `python3 tests/period_deaths_browser.py`：8項既有期間查詢、明細／CSV一致性、缺資料、唯讀及72組螢幕／語言／字級檢查通過。
- `python3 tests/pwa_test.py`：5項更新／快取檢查通過。
- 私有隔離驗證：載入目前農場資料，JD-115-20.21選取後顯示5/22～10/18累計83隻，點進歷史合計同為83。15／21棟分日進場的JD-115-40.41從10/9起算，保留兩棟並顯示實際已登記合計。全部既有紀錄及品質核對狀態不變。
