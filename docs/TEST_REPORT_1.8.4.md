# PigLedger 1.8.4：飼料日期＋噸數（棟號）

每週報表增加逐筆feed_details，沿用原日期、單棟批次分配公斤與穩定紀錄ID，不新建／變更叫料。A4列印及預覽把飼料列改為`10/12+2（13）`，同週各筆分行；小數噸數保留，整數不補小數零。總合計不變，CSV保留數字週表並增加簡寫及原日期／棟舍／公斤／噸明細。

## 驗證

- `sh scripts/check.sh`：246項單元／整合測試及8份JavaScript語法檢查通過。
- 每週報表計算13項單元測試通過，新增兩項涵蓋日期週界、同日不同筆、同棟多筆、單棟篩選、總公斤一致、作廢排除及全場未歸屬不捏造明細。
- 真實Chromium／隔離SQLite／HTTP的10組報表情境驗證使用者範例：10/12、2000公斤、13棟顯示`10/12+2（13）`；同週另有13／22棟各筆，全部保留，合計5000公斤；單棟只顯示自身資料，未指定批次仍標待補。
- 實際下載CSV含週數字合計、簡寫及完整資料；實際產生短期與39週PDF，pdfinfo核對1頁A4直式，轉圖檢查飼料逐筆沒有裁切。很多筆時可自然續頁，避免省略紀錄。
- PWA更新與草稿保護5項檢查通過；新版資產有版本化快取，API與報表內容不放進離線資產快取。繁中／越南語及原權限保留。
- 修改前原Turso保護區備份70筆records、4個帳號、12筆秤重及110筆操作紀錄；正式部署核對新版資產與資料指紋。資料庫結構、原資料、帳號、存欄、ADG及FCR規則不變，沒有將叫料改成實耗。

正式農場目前沒有已保存叫料紀錄，因此逐筆內容以隔離合成資料驗證；沒有把範例寫進正式資料庫。實體手機、Safari與印表機仍待驗收，不把Chromium產生PDF當作實機通過。
