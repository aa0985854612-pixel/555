# PigLedger 1.5.1 測試與資料保留報告

本版修正單棟Excel來源批次的入場頭數被鎖死問題。管理員可在原批次編輯表單更正，必填原因，顯示原Excel數量、目前保存數量及本次差額。更正套用於原入場存欄及育成率分母，不生成補豬、盤點或死亡事件。沒有替使用者猜測或改填正式入場數字。

## 本地真實執行與合成資料

- `sh scripts/check.sh`：184個單元／API／儲存測試通過，0失敗、0略過；三份JavaScript語法檢查通過。
- 新增12個入場數更正案例：增加與減少後存欄及育成率重算、退出頭數不變、歷史日期、重複投影不重算、必填原因、非整數／空白／負數及不足頭數拒絕、伺服器角色、重送去重、舊revision衝突、來源引用不可移除、操作前後值、備份還原、重匯不覆蓋、來源作廢與更正共存、後續異動不能變負、其他批次欄位修改保留更正原因。
- `python3 tests/entry_correction_browser.py`：4組真實Chromium情境通過；使用獨立合成資料。手機尺寸下直接編輯單棟來源批次、必填原因及差額、真實表單PUT與保存後重讀、三輪語言／同步保留草稿、取消不保存均已驗證。
- `python3 tests/upgrade_browser.py`：7組既有介面／權限／來源歷史情境通過。
- `python3 tests/pwa_test.py`：5項版本快取及更新保護檢查通過。
- 以上瀏覽器合計16組／項通過；是桌面Chromium與模擬手機視窗，不是手機實機。

## 真實Turso

修改程式前，已在原Turso建立持久備份，核對既有資料結構、原批次及帳號權限。沒有重建資料庫、重設帳號或執行SQL結構遷移，仍使用schema4。

使用真實Turso交易執行單棟入場數更正並檢查交易內的投影：進場及剩餘頭數同步改變，原死亡、出豬、淘汰及來源工作簿不變。測試交易以ROLLBACK結束，核對全份records、users、requests、audit、account_security指紋不變；沒有留下測試更正或測試稽核。

原有正式入場數並未因本版更新而更改。原入場均重補登、人工確認的異動、帳號密碼及歷史保留。新增的entry_count_reason存在原records內，真正使用更正時才寫入。更正後讀取與備份還原需1.5.1以上程式，不可回退1.5.0混用原來源基準。

## 正式部署與尚未驗收

沿用原GitHub main、原Vercel專案、原HTTPS網域及Turso。Git推送自動觸發部署；本版無需補環境變數或重建資料庫。部署狀態以Vercel API實際READY及正式網域綁定為準。

維護建置內曾成功取得正式HTTPS首頁及health HTTP200（當時為更新前版本）；新版部署後的HTTP核對結果另在維護紀錄保存。此結果不等於以真實使用者密碼完成公開HTTPS瀏覽器登入。

尚未驗收：使用者目前密碼的正式網站登入、實體Android／iPhone／iPad操作、真正手機加入主畫面。未宣稱這些測試通過。原使用者密碼未知，不為測試重設。
