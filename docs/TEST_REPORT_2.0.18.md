# PigLedger 2.0.18：分次進場同批的統一週表

15、21棟同批分次進場，原先因整批無單一共同週齡，沒有預排至32週，導致週欄很少且特別寬。現在提供具名的最早進場棟舍作為紙本週次基準，維持上下兩排與32週後兩個空白欄。共同entry_age_days與各週age_week仍為空，不捏造整批同齡；新增week_reference僅描述具名的排表依據。

各棟的進場日期、頭數、日齡及均重保留；單棟查詢各自計週。若最早進場的棟舍日齡未知，不借用較晚入場棟舍作假基準。新欄位只在唯讀報表中產生，沒有資料庫結構或環境變數修改。前次確認的料桶1四筆各半分配仍保留。
