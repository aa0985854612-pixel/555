# Excel 資料移入 — v1.2.0

管理員在設定選「肉豬各周存欄頭數」原始XLSX，填實際盤點日期、每行棟號/頭數、已出完棟號，先預覽再匯入。角色與CSRF由伺服器驗證。

讀取已儲存的值，不執行公式。原檔所有工作表、公式、備註及舊表以原始位元組保留，舊表不加入目前頭數。逐組進场－正常出豬－淘汰－死亡－遺失必須等於存欄；各組合計也必須與表頭一致。缺樣本頭數的原均重僅顯示參考來源，不新增假的1頭抽樣、不拿來算加權均重或FCR。

概略分棟數以最大餘數法分配整數，維持原表每組合計，標示暫定。缺一棟可由同組合計推回。差距超過max(3頭,同組5%)先要求核對，不能當作小幅調整。只用日期明確且明細合計可核對的備註回推31日內盤點；缺日期或口徑不足保留未知。

普通出豬明細含市場死亡時，只有在簡單加總公式、各日期及儲存格總數能核對時，才用公式的正常出豬數、死亡另列，保留原文及證據。備註沒寫棟舍的事件保持未指定，不能成為某棟真實歷史事件；為維持當前合計作的存欄分配仍標示估計。

每棟建立獨立批次ID，共用原表組別。合併批次沿用原表名稱，採首次進場日計齡，原始不同進場明細保存在來源備註。已出完棟舍標記結束。内部轉棟承接共同來源豬群，接收批次0頭，不重複計全場進場。

多棟只有整組進場／死亡合計時，單棟分母及育成率未知；全組／全場用可靠原表總數，淘汰不降低育成率。来源期間累計已反映歷史異動，歷史頁／CSV只展示來源事件，不再次扣除。新豬隻異動從基準次日開始；可靠的歷史飼料／秤重仍可補登；管理員可於基準日登記盤點調整，保留原值、調整及歷程。

來源事件在歷史頁唯讀，篩選與CSV一致，CSV包含calculation_source及source_cell。未知棟別只在日期／類型或整組查詢顯示，不塞入單棟。缺資料的截至日／區間顯示未知，不把原表累計混作區間新增0頭。

同檔SHA-256固定來源ID去重，重送、多人匯入、還原不重複。交易失敗整批回滾；重匯不覆蓋管理員日齡更正。匯入前自動備份。schema3完整備份含原始XLSX，接受schema1／2舊備份；舊App拒絕新資料庫版本，不降版重建。

跨設備完整備份遇同名不同ID帳號會提示衝突並保留目的地帳號，不清庫重來；可改匯入原始Excel。Windows首次匯原表一次，手機使用同一筆電資料，不另外匯一份。真實農場資料只在登入後的資料庫、私密來源及備份，不放GitHub程式包或測試fixture。
